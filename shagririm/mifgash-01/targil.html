שאלון קטן ב-Apps Script, עם Gemini

מפגש 1 · מסלול ההובלה · צעד 5. בחשבון ג'ימייל פרטי וב-Gemini החינמי. כ-25 דקות.
התוצר: קישור לשאלון על האתגר שהבאתם מבית הספר, שבו כל תשובה נכנסת לגיליון שלכם. שולחים אותו כבר מחר.

הצעדים

1

גיליון חדש

נכנסים ל-sheets.new ונותנים לו שם, למשל "משוב הדרכה". משאירים את הגיליון ריק.

2

פותחים את Apps Script מתוך הגיליון

בתפריט של הגיליון: Extensions (בעברית: תוספים) ← Apps Script. נפתח עורך עם קובץ Code.gs ריק.

  1. לוחצים על Extensions (תוספים), ובתפריט שנפתח: Apps Script.
3

מבקשים מ-Gemini את הקוד

ב-gemini.google.com מדביקים את הפרומפט:

אני רכז/ת חדשנות בבית ספר. אני רוצה לבנות שאלון משוב קצר אחרי הדרכה שהעברתי לצוות, ב-Google Apps Script שמחובר לגיליון Google (הסקריפט נפתח מתוך הגיליון: תוספים ← Apps Script). מה השאלון צריך לעשות: - דף ווב בעברית, מימין לשמאל, שנראה טוב בטלפון. - שלוש שאלות: 1. עד כמה ההדרכה הייתה שימושית לך? (דירוג 1 עד 5) 2. מה תנסה/י כבר השבוע בעקבות ההדרכה? (טקסט חופשי) 3. על מה היית רוצה הדרכה הבאה? (בחירה: כלי AI לכתיבה / בדיקת עבודות / הכנת חומרי למידה / אחר) - בלחיצה על "שליחה", התשובה נשמרת כשורה חדשה בגיליון, עם תאריך ושעה, ומופיעה הודעת תודה. תן לי: 1. את הקוד המלא של Code.gs 2. את הקוד המלא של קובץ Index.html 3. הוראות צעד אחר צעד: איפה להדביק כל קובץ, איך להריץ בפעם הראשונה ולאשר הרשאות, ואיך לפרוס כ"אפליקציית אינטרנט" כדי לקבל קישור שאפשר לשלוח לצוות. כתוב קוד פשוט, עם הערות קצרות בעברית.

האתגר שלכםבפרומפט יש דוגמה: משוב אחרי הדרכה. מחליפים את המשפט הראשון באתגר שהבאתם, ואת שלוש השאלות בשאלות שיעזרו להבין אותו. כותבים גם למי השאלון מיועד: צוות, מנהל/ת, תלמידים או הורים. כל השאר נשאר אותו דבר.

4

מדביקים את שני הקבצים

  1. מוחקים את מה שכתוב בעורך (function myFunction), ומדביקים במקומו את הקוד של Code.gs מ-Gemini.
  2. לוחצים על + ליד "קבצים" ← HTML. קוראים לקובץ Index (בלי .html, העורך מוסיף לבד), ומדביקים בו את הקוד השני.

שומרים: Ctrl+S, או אייקון הדיסקט בסרגל.

5

פורסים

זה החלק הארוך. הולכים לפי התמונות, לפי הסדר.

א. בוחרים סוג פריסה

  1. לוחצים על הכפתור הכחול לפריסה (באנגלית: Deploy) ← פריסה חדשה.
  2. בחלון שנפתח לוחצים על גלגל השיניים ליד "בחירת סוג".
  3. בוחרים אפליקציית אינטרנט.

ב. מי יכול לפתוח: כולם

  1. ב"למי יש גישה" בוחרים כולם. בלי זה, הצוות לא יוכל לפתוח את השאלון. "לבצע בתור" נשאר עצמי.
  1. בודקים שכתוב כולם.
  2. לוחצים לפריסה.

ג. מאשרים גישה (רק בפעם הראשונה)

  1. לוחצים הרשאת הגישה, ובוחרים את חשבון הג'ימייל שלכם.

עכשיו מגיע מסך באנגלית שנראה מפחיד. זה תקין: גוגל מזהיר על כל קוד שלא עבר בדיקה שלו, וזה הקוד שלכם.

  1. לוחצים על הקישור הקטן Advanced (מתקדם). לא על הכפתור הכחול.
  2. לוחצים על Go to … (unsafe) שמופיע למטה.
  1. גוללים למטה ולוחצים Continue (או Allow).

ד. מעתיקים את הקישור

  1. תחת "אפליקציית אינטרנט" יש כתובת שמסתיימת ב-/exec. לוחצים העתקה. זה הקישור ששולחים.
6

בודקים

פותחים את הקישור בטלפון וממלאים. אם בגיליון נוספה שורה, זה עובד. זו גרסה 1.

איפה נתקעים, ומה עושים

מה רואיםמה עושים
"Google hasn't verified this app" / "גוגל לא אימתה את האפליקציה"Advanced / מתקדם ← Go to … (unsafe) ← Continue. זה הקוד שלך, והגישה רק לגיליון שלך. התמונות בצעד 5, חלק ג.
אין אפשרות "כל אחד" ב"למי יש גישה", או שההרשאה נחסמתחשבון בית ספרי שמנוהל על ידי ארגון. עוברים לג'ימייל פרטי.
שגיאה בהרצה, או שהשאלון נשלח ושום שורה לא נוספתמעתיקים את הודעת השגיאה המלאה ל-Gemini: "קיבלתי את השגיאה הזאת, מה לתקן?". מדביקים את התיקון ושומרים.
תיקנתי את הקוד, והקישור עדיין מציג את הגרסה הישנהפריסה ← ניהול פריסות ← עריכה (עיפרון) ← גרסה: חדשה ← פריסה. כך הקישור נשאר אותו קישור. "פריסה חדשה" יוצרת קישור חדש.
הדף עולה בלי עיצוב או משמאל לימיןמבקשים מ-Gemini: "הוסף dir=rtl ו-meta viewport לקובץ Index.html".

Code.gs

// מציג את השאלון
function doGet() {
  return HtmlService.createHtmlOutputFromFile('Index')
    .setTitle('משוב על ההדרכה')
    .addMetaTag('viewport', 'width=device-width, initial-scale=1');
}

// שומר תשובה כשורה חדשה בגיליון
function saveAnswer(a) {
  var sh = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  if (sh.getLastRow() === 0) {
    sh.appendRow(['תאריך', 'שימושיות (1-5)', 'מה אנסה השבוע', 'הדרכה הבאה']);
  }
  sh.appendRow([new Date(), Number(a.useful), a.next, a.topic]);
  return true;
}
